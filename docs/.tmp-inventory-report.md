## 五、为什么会有这么多

关键线索：**`.tmp-web-*` 系列有 30+ 个目录，每个约 136 MB**。
它们对应历次发布时的独立构建输出目录。

这与已知的沙箱约束有关：**同一 `outDir` 二次 build 会 EPERM**，
所以每次发布都要换一个全新的临时目录 —— 目录越攒越多，且没有任何清理环节。

### ✅ 长效机制（已实施）

1. **新增 `scripts/clean-tmp.mjs`**：安全清理工具，特性：
   - 默认 **dry-run**，必须显式 `--yes` 才删除
   - 只删「项目根目录下、以 `.tmp-` 开头」的条目，绝不递归到别处

   - **永不抛错**——清理失败只打警告，不影响发布结果
