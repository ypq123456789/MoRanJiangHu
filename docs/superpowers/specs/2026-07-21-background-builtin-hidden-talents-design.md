# 背景自带天赋与隐藏天赋设计

**日期：** 2026-07-21  
**状态：** 待实现  
**范围：** 开局背景/天赋机制；不包含悟道/战斗力评分玩法等叙事规则细节。

## 目标

让特殊背景（例如「唯心剑修」）在**无论玩家如何选择可选天赋**时，都强制附带若干天赋（例如「剑在心中」）。  
同时允许天赋标记为**隐藏**：不进入选择池，只能通过背景引用等方式注入。  
玩家自选天赋始终是**额外叠加**，不因背景自带而被禁止或顶替。

## 非目标

- 不在本期决定「绝境 AI 自动突破」或「玩家口胡 + AI 打分开悟」的玩法。
- 不改造 NPC 推断出身/天赋算法（除非为兼容规范化字段必须透传）。
- 不强制上线「唯心剑修」内容包；机制就绪后可另开内容任务。

## 数据模型

### 天赋结构（天赋池）

在现有 `天赋结构` 上扩展：

```ts
interface 天赋结构 {
  名称: string;
  描述: string;
  效果: string;
  叙事约束?: string;
  隐藏?: boolean; // true = 不进抽卡/列表选择池
}
```

- 缺省 / `false`：与现网一致，可进入选择池。
- `true`：过滤出选择池；仍可被背景引用并进入角色最终 `天赋列表`。

### 背景结构（背景池）

在现有 `背景结构` 上扩展**引用字段**（不内嵌完整天赋定义）：

```ts
interface 背景结构 {
  名称: string;
  描述: string;
  效果: string;
  初始物品?: ...;
  可选初始物品?: ...;
  开局货币?: ...;
  自带天赋?: string[]; // 引用天赋池中的名称，按顺序 resolve
}
```

- 引用键：**名称**（与开局预设 `天赋名称列表` 一致，避免引入第二套 ID）。
- 解析：在可用天赋目录中按名称查找完整 `天赋结构`。
- 解析失败：跳过该引用并诊断日志，不阻断开局。

### 角色最终天赋

```text
最终天赋列表 = 去重合并(
  玩家自选天赋,
  resolve(当前出身背景.自带天赋)
)
```

- 同名：一条即可，定义以天赋池解析结果为准。
- 玩家自选与自带同名：仍一条，视为已满足。
- **不互斥**：有自带不限制再选其它天赋。

## 规则约定

| 规则 | 约定 |
|------|------|
| 可选上限 | 仅统计**玩家自选**；自带不计入「最多 N 个」 |
| 是否可卸自带 | 默认**不可卸**；UI 标记「背景附带」 |
| 换背景 | 移除「仅因旧背景附带、且非玩家自选」的天赋；注入新背景自带 |
| 选择池 | `可见天赋 = 全目录.filter(t => t.隐藏 !== true)` |
| 抽卡/重 roll | 只从可见天赋抽 |
| 自定义天赋编辑 | 可勾选「隐藏」；自定义背景可填自带引用名 |
| 旧数据 | 无新字段 = 行为与现网一致 |
| 工坊模式包 | `payload.talents[].隐藏`、`payload.backgrounds[].自带天赋` 随池注入 |
| 叙事约束 | 自带天赋若带 `叙事约束`，走现有 `提取叙事约束块` 管线，无需新通道 |

## 与现有能力的关系

| 能力 | 关系 |
|------|------|
| 开局预设 `背景名称 + 天赋名称列表` | 保留，作推荐套装；**不替代**背景自带机制 |
| 模式包 backgrounds / talents 池 | 继续扩池；自带引用在该联合目录中 resolve |
| 叙事约束 | 复用；适合特殊背景隐藏天赋写硬规则 |
| 背景初始物品/货币 | 不变 |

## 关键面

- 类型：`types.ts`、`models/system.ts`（runtime snapshot 若快照背景/天赋需带新字段）
- 规范化：`openingConfig`、`stateTransforms` 出身/天赋标准化
- 合并工具：`customNewGamePresets` 合并去重需保留 `隐藏` / `自带天赋`
- 开局向导：桌面 + 移动（池过滤、换背景 merge、成角落盘、UI）
- 工坊：模式包读写透传（不必强制编辑 UI 一期做完，但 JSON 要 round-trip）
- 测试：单元测试覆盖隐藏过滤、引用解析、叠加、换背景、上限

## 风险与缓解

1. **换背景误删玩家自选** → 以「玩家自选名称集合」为准剥离旧自带。  
2. **隐藏天赋玩家看不见已获得** → 已获得区必须展示并标注来源。  
3. **引用悬空** → 软失败 + 日志；工坊后期可加校验。  
4. **双端向导分叉** → 抽共享纯函数，桌面/移动共用 merge 与过滤。

## 成功标准

1. 选带 `自带天赋` 的背景后，不选手动天赋也能在成角角色上看到自带项。  
2. 再选手动天赋后，最终列表为并集，不互斥。  
3. `隐藏: true` 的天赋不出现在抽卡/列表池，但可因背景出现在最终列表。  
4. 旧存档/无字段背景行为不变。  
5. 相关单元测试通过。
